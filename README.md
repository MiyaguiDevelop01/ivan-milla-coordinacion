# Iván Milla · Coordinación y Operaciones

Portfolio profesional estático preparado para GitHub Pages.

## Publicación
1. Crear un repositorio público llamado `ivan-milla-coordinacion`.
2. Subir todos los archivos a la raíz.
3. Activar Settings > Pages > Deploy from a branch > main > /(root).

## Privacidad
No incluye DNI, domicilio, teléfono, TIP ni documentación acreditativa.
